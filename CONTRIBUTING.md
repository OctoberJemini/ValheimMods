# Contributing

Use the issue forms for bugs and suggestions. One issue per problem makes reports easier to follow. Include the affected mod and versions; reduce the reproduction to the smallest practical setup.

For code changes, describe the behavior before and after, how it was checked, and any compatibility impact. Preserve plugin GUIDs and prefab identifiers unless a migration is explicitly provided. Never commit game DLLs, credentials, local configuration, logs, or world saves.

Projects linked to existing repositories accept code changes in those repositories. Shared issues here can be cross-linked rather than duplicated.
