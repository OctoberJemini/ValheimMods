# 1.1.0

- Resolve chest identity from the network prefab; numbered dungeon copies now receive rewards.

- Include early-biome treasure chests, burial chambers, troll caves, sunken crypts, frost caves and all treasure-prefab dungeon variants.

- Scale early-biome coins down; preserve Mistlands, Ashlands and Deep North amounts and 2% jackpot odds.

- Preserve original non-coin loot and one-time generation rules. Existing generated chests remain unchanged.
