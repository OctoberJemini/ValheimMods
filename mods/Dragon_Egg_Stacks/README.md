# Dragon Egg Stacks 1.0.0

Choose **Dragon Egg Stacks** in the report form and include the mod version, Valheim version, steps to reproduce, and relevant logs or screenshots.


Allows dragon eggs to stack up to 50 per slot. Only the dragon egg maximum stack size is changed. Existing weight and teleport settings are preserved.

Works alongside ItemStacks, including its database refreshes. Stack size can be configured in BepInEx/config/OctoberJemini.DragonEggStacks.cfg after first launch.

Install through a Thunderstore-compatible mod manager and restart Valheim. For manual installation, copy the included plugins folder contents into BepInEx/plugins. Existing separate eggs can be combined manually. Multiplayer participants should use the same stack limit.

Built against the installed Valheim, BepInEx and Harmony assemblies with warnings treated as errors. In-game combining/splitting still needs testing.
