Choose **Building Pieces** in the report form and include the mod version, Valheim version, steps to reproduce, and relevant logs or screenshots.


OctoberJemini's additional building pieces in one package.

- Tower Stairs 0.4.2
- Roof Corners 45 0.4.0
- Inverted Stone Ramp 1.1.2

Requires BepInEx and Jotunn. Install matching versions on the server and all clients.

The included plugins retain their existing identifiers, configuration files and building-piece prefab IDs. When replacing separate local installations, remove the previous copies of these three DLLs so that each plugin is installed only once. Keep this package installed while your world contains its pieces.

Compact Crafting Upgrades remains a separate published mod.

Includes the existing local builds. Compilation and geometry checks were performed during development. In-game placement and multiplayer verification remain pending.
