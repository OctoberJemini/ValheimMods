# Auto Wishbone & Andvaranaut

Carry a Wishbone to activate its finder without using an equipment slot. If Epic Loot is installed, carrying Andvaranaut activates its treasure finder too.

Both items must be in your player inventory. Their status icons remain visible in the status-effect row while active, even when no target is nearby. Detection ranges and proximity pulses use the original item effects. Multiple copies do not multiply the effect.

## Compatibility

Epic Loot is optional. Without it, the vanilla Wishbone works normally. With it, the mod uses Epic Loot's Wishbone and Andvaranaut effects, retaining their separate detection rules. This mod does not grant either item.

## Installation

Install BepInExPack Valheim, then copy the package's plugins folder into BepInEx. This is the renamed Inventory Finders mod. Disable/remove Inventory Finders before installing this replacement; your existing settings remain compatible. Remove the older Always Andvaranaut and Inventory Wishbone plugins before using this combined replacement. Restart the game.

## Configuration

`OctoberJemini.InventoryFinders.cfg`: General / Enabled controls inventory activation.

## Validation

Compiled against local Valheim assemblies. Passed 21 isolated lifecycle checks covering optional Epic Loot, inventory removal, equipment interactions, death, and status visibility. In-game validation is still pending.
