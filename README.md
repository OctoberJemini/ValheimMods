## Reporting problems

Search existing issues, then choose the bug-report form. We support only the latest release of the affected mod and Valheim. Update both before reporting a bug. Select the affected mod and include whether you play locally or on a server, reproduction steps, and a relevant log excerpt. Screenshots help with building and map issues. Do not upload world saves or credentials to a public issue.

This is a community mod project, not affiliated with Iron Gate. Downloads and dependency lists are on Thunderstore. Source snapshots here are not a guarantee of compatibility with every game update or mod combination.

## Development

See [BUILDING.md](BUILDING.md) and [CONTRIBUTING.md](CONTRIBUTING.md). Game, BepInEx, Harmony, Jotunn and other third-party DLLs are not distributed here.

[Safe Item Stacks](./mods/Safe_Item_Stacks/) is available as development source, including offline policy tests. It has not been published or playtested in game; its prepared package version is not a store release.
